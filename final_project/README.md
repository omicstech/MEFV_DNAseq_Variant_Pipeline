# MEVF_F16 Genomic Analysis Pipeline

## Project Purpose
This project analyzes MEVF_F16 dataset using a standard NGS pipeline.

## Pipeline Steps
1. Quality Control (FastQC)
2. Alignment (BWA)
3. Variant Calling (GATK / samtools)
4. Annotation (VEP / ANNOVAR)
5. Visualization (IGV)

## Folder Structure
- data/ → raw data & reference genome
- analysis/ → QC, alignment, variants, annotation
- figures/ → plots and figures
- reports/ → final report files
- scripts/ → pipeline scripts
- igv/ → IGV visualization files

## Tools Used
- FastQC
- BWA
- samtools
- GATK
- IGV
